## Queue

- D-008 — `accept`/`reject` refusent `paragraph-mark-ins` (marque de paragraphe **insérée**), la lettre du scope J02-P6 ne couvrant que la marque supprimée. Conséquence : `accept(pkg)` sans filtre lève `UnsupportedRevision` en bloc sur tout document portant une marque de paragraphe insérée — cas courant dès qu'un relecteur ajoute un paragraphe. Options : (a) part de suivi (T3, S) qui ajoute le genre — accepter = retirer la marque, rejeter = fusionner avec le paragraphe suivant, la machinerie `_merge_into_next` est déjà écrite et testée ; (b) garder le refus et le documenter comme limite connue jusqu'à J03-P2. Reco : (a) — un `accept` global qui échoue sur un document ordinaire rend l'outil migré en J03-P2 inutilisable, et le coût est faible puisque le mécanisme existe. Bloque : rien en J02 ; J03-P2 migre `tracked_changes` par-dessus. Source : REPORT J02-P6.
- D-006 — Le jalon écrit `stories=("body",)` alors que `DocxPackage.stories()` nomme le document principal `"document"`, et `Match(story, paragraph, index, …)` laisse ambigu ce que porte `index`. J02-P5 a tranché : `"body"` = alias exclusif de `"document"` en entrée, `Match.story` rapporte toujours l'id réel ; `paragraph` = élément `w:p` vivant, `index` = entier V2 séparé, `None` pour un paragraphe en cellule de tableau. Options : (a) entériner ces deux choix et aligner le vocabulaire des jalons J03/J04 dessus ; (b) supprimer l'alias `"body"` et n'exposer que les ids de `stories()`. Reco : (a) — l'alias est documenté et sans ambiguïté, et `index: int | None` dit une vérité de l'adressage V2 (les cellules sont hors de l'espace d'index). Bloque : rien ; J03-P1 et J04-P1 réutilisent `iter_paragraphs`. Source : REPORT J02-P5.
- D-005 — Résultat en cache d'un champ imbriqué (`PAGE` dans l'instruction d'un `IF`) : `w:t` ordinaire, donc lu comme visible ; `fields()` rend `"1first page"` là où Word n'afficherait que `"first page"`. Options : (a) lecture mécanique, `fields()` signale les deux spans, `ranges`/`find` refusent d'y couper — déjà implémentée et testée en J02-P2 ; (b) masquer le résultat des champs imbriqués sous une instruction, ce qui demande d'évaluer la structure des champs. Reco : (a) — le moteur rapporte ce que le paquet stocke ; (b) revient à simuler le moteur de champs de Word. Bloque : rien (J02-P3/P5 s'appuient sur le comportement actuel ; (b) les rouvrirait). Source : REPORT J02-P2.
