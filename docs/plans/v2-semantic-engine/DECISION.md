Options : (a) part de suivi (T3, S) qui ajoute le genre — accepter = retirer la marque, rejeter = fusionner avec le paragraphe suivant, la machinerie `_merge_into_next` est déjà écrite et testée ; (b) garder le refus et le documenter comme limite connue jusqu'à J03-P2. Reco : (a) — un `accept` global qui échoue sur un document ordinaire rend l'outil migré en J03-P2 inutilisable, et le coût est faible puisque le mécanisme existe. Bloque : rien en J02 ; J03-P2 migre `tracked_changes` par-dessus. Source : REPORT J02-P6.
